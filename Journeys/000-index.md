# User Journeys

Each file in this folder documents one user flow end-to-end: the goal, the
steps, what the UI should do at each step, and what counts as "done". These
are specs for what the editor should feel like — code and plan files have
to meet them.

## Index

1. **[001 — New File](001-new-file.md)** · Opening the editor fresh and
   getting a scene to paint on.
2. **[002 — Agent Connecting](002-Agent-Connecting.md)** · PIN + token
   handshake an agent uses to earn access to the editor.
3. **[003 — Elevated Corners](003-Elevated-Corners.md)** · Elevating
   shared corners of tiles.

Future journeys are authored by the user. Don't invent new numbered
journey files without being asked.
